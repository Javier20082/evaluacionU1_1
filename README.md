## ¿Que es una rama?
En GitHub una rama es una línea de desarrollo independiente dentro de un repositorio permite trabajar en nuevas funcionalidades corregir errores o hacer pruebas sin afectar directamente la versión principal del código.
## ¿Qué es la rama main?
La rama main es la versión principal y confiable de tu proyecto donde todo está probado y listo para poder usarse.
